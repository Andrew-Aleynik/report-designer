Конструктор отчетов — краткая инструкция

1. Структурная модель объекта
• Создайте корневой элемент («Добавить новую модель») — это объект отчёта.
• В дереве через контекстное меню добавляйте дочерние элементы, редактируйте и удаляйте узлы.
• Каждому элементу можно назначить тип и потребительское качество.
• Кнопка «Выгрузить в PDF» формирует отчёт по выбранной модели.

2. Потребительские качества
• Выберите качество в списке или создайте новое.
• Заполните код, срок службы, граничное условие и фактическую стоимость.
• Добавьте свойства: укажите название, группу свойств, критерий и размерность.
• Группы свойств нужны, чтобы на вкладке интенсивностей свойства отображались отдельными таблицами.
• Для дочерних элементов можно наследовать свойства родителя.

3. Внешние воздействия
• Добавьте внешние воздействия и при необходимости группы воздействий.
• Эти данные используются при заполнении значений свойств по уровням интенсивности.

4. Интенсивности внешних воздействий
• Выберите потребительское качество.
• Добавьте интенсивности для нужной группы свойств (например, «низкая», «средняя», «высокая»).
• Для каждой группы свойств заполните таблицу: внешнее воздействие и значения по интенсивностям.
• Удалить интенсивность можно через список в верхней части вкладки.

Рекомендуемый порядок работы: модель → качества и свойства → воздействия → интенсивности → выгрузка PDF.
